# Diplom_2: API автотесты для Stellar Burgers

## Задание 2: Автотесты для API

### Автотесты для проверки API сервиса Stellar Burgers

### Реализованные сценарии

Созданы автотесты, покрывающие основные эндпоинты API:

#### Создание пользователя
- Создание уникального пользователя
- Попытка создания уже зарегистрированного пользователя  
- Создание пользователя без обязательных полей (email, password, name)

#### Логин пользователя
- Успешный вход под существующим пользователем
- Вход с неверным логином и паролем

#### Создание заказа
- Создание заказа с авторизацией и ингредиентами
- Создание заказа без авторизации
- Создание заказа без ингредиентов
- Создание заказа с неверным хешем ингредиентов

### Технологии и подходы

- **pytest** - фреймворк для тестирования
- **requests** - для HTTP запросов к API
- **allure-pytest** - для создания детальных отчетов
- **Параметризация** - для тестирования различных сценариев
- **Фикстуры** - для переиспользуемых данных и настроек
- **Изоляция тестов** - каждый тест создает и удаляет своего пользователя
